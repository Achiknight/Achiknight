# 🛠️ `WHAT I'M BUILDING`

## 📓 Journal Day Tracker

A personal desktop journaling and day-tracking application.

Built while learning how to structure a real application instead of putting everything into one giant file.

### Stack

`Python` `CustomTkinter` `SQLite` `MySQL` `JSON` `Git`

### Architecture

```text
Journal-Day-Tracker
│
├── Backend/
│   ├── configuration
│   ├── application logic
│   └── database operations
│
├── DBFile/
│   ├── connections
│   └── journal types
│
├── Gui/
│   ├── Front Page
│   ├── Settings
│   ├── Track Selection
│   ├── Writer Page
│   └── Name Journal
│
├── utility/
│
└── Main.py
```

### Things I'm learning from it

* GUI architecture
* Database abstraction
* SQLite / MySQL handling
* Configuration systems
* Theme management
* Reusable widgets
* Project organization
* Git workflows

> A project doesn't need to be huge to teach you something huge.
